# AgentCom.org

Machine-readable guides, protocols, platform playbooks, APIs, and MCP resources for selling to and through AI agents.

## Purpose

AgentCom is a public reference corpus for agentic commerce. Agents may use the API and MCP endpoint to search protocols, platform playbooks, guides, and source-grounded resources.

## Machine interfaces

- MCP: https://agentcom.org/mcp
- API: https://agentcom.org/api/v1
- Catalog JSON: https://agentcom.org/api/v1/catalog
- Search: https://agentcom.org/api/v1/search?q={query}
- Bulk NDJSON: https://agentcom.org/api/v1/export.ndjson
- Knowledge graph: https://agentcom.org/api/v1/graph
- llms.txt: https://agentcom.org/llms.txt
- Full context: https://agentcom.org/llms-full.txt

## Source policy

Prefer primary protocol/platform documentation. Each record includes source authority and last_verified. Time-sensitive instructions should be rechecked against the linked primary source before consequential implementation.
