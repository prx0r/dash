# Campaign blueprint — how every file below is built

Each campaign distills: template (graph shape) + teardown (ranked pains) +
ONS/Skills-England demand + legislation/regulatory pack + stack research +
Big4/govt reports. The JSONs are guides, not scripts — judgment fills gaps.

## Evidence rules

- Real numbers only from verified sources (ONS, Skills England, fee pages,
  legislation text, vendor pricing checked 2026). Everything else is TBD:.
- No invented prices, volumes, or conversion rates. Drop's failure mode was
  36 shells of "See market data" — these files invert it: numbers where known,
  TBD where not, never vibes.
- Each campaign ends with Evidence bindings (claim → source) + 12-gate states
  (honest UNKNOWNs allowed; UNKNOWN blocks, never passes).

## File structure (10 sections, drop-compatible)

1. Market overview (demand numbers + why now)
2. Acquisition (channels with owner + maths where known)
3. Offer catalog (services/products, prices or TBD)
4. Unit economics (margin math, Blended where estimated→marked)
5. Supply/operations strategy
6. Distribution strategy
7. Listing/feed structure (what the agent reads + publishes)
8. Landing/conversion structure
9. Success metrics + kill rules
10. Next steps (M-tasks executable now, H-tasks queued)
+ Evidence bindings + 12-gate states + teardown ref + template ref
